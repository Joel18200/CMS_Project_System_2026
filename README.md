# Clinic Management System (CMS)

A Django and MySQL project developed collaboratively.

## Getting Started

Follow these steps to set up the project on your computer after cloning the repository.

### 1. Clone the repository

Open Command Prompt or a terminal and run:

```bash
git clone <REPOSITORY_URL>
```

Replace `<REPOSITORY_URL>` with the URL of this GitHub repository.

### 2. Open the project in VS Code

Move into the cloned project folder and open it in VS Code:

```bash
cd CMS_26
code .
```

> If your cloned folder has a different name, use that folder name in the `cd` command.

### 3. Create and activate a virtual environment

Create the virtual environment:

```bash
python -m venv myvenv
```

Activate it on Windows Command Prompt:

```bat
myvenv\Scripts\activate
```

When it is active, your terminal prompt should begin with `(myvenv)`.

### 4. Install the required packages

Upgrade pip and install the project's dependencies:

```bash
python -m pip install --upgrade pip
pip install django djangorestframework mysqlclient
```

### 5. Configure MySQL

Make sure MySQL Server is installed and running.

Create a database named `cms_26` in MySQL:

```sql
CREATE DATABASE cms_26;
USE cms_26;
```


Configure the database connection in `CMS_26/settings.py` to match your local MySQL username, password, host, and port. Do not commit personal credentials to Git.
```
DATABASES = {
    "default": {
        "ENGINE": "django.db.backends.mysql",
        "NAME": "cms_26",
        "USER": "root",
        "PASSWORD": "<sql_password>",
        "HOST": "127.0.0.1",
        "PORT": "3306",
    }
}
```
### 6. Apply database migrations

Run the migrations included in the repository to create the database tables:

```bash
python manage.py migrate
```

> You normally do not need to run `makemigrations` just to set up a fresh clone. Run it when you change Django models and intend to create new migration files.

### 7. Create an admin account (optional)

To access Django Admin, create your own superuser:

```bash
python manage.py createsuperuser
```

Follow the prompts in the terminal.

### 8. Check and run the project

Check the Django configuration:

```bash
python manage.py check
```

Start the development server:

```bash
python manage.py runserver
```

Open the local development server at:

- Application: http://127.0.0.1:8000/
- Django Admin: http://127.0.0.1:8000/admin/

Press `Ctrl + C` in the terminal to stop the server.

## Working with Models

If you modify or add models:

```bash
python manage.py makemigrations
python manage.py migrate
```

Commit the migration files generated by `makemigrations` along with your model changes so the rest of the team can apply them.

## Notes

- Keep your virtual environment and credentials out of Git.
- Each team member should use their own local database credentials.
- Do not delete or edit existing migration files just to resolve a local setup issue.
